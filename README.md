# 🎬 Movie Streaming Web App

A modern movie web application built with React that allows users to discover movies, search for titles, and watch trailers.

---

## ✨ Features

- 🔎 Search movies by title
- 🎞️ Watch movie trailers (YouTube player)
- 📄 Pagination (Load More movies)
- ⚡ Fast and responsive UI
- 🎨 Clean and modern design

---

## 🛠️ Tech Stack

- React.js
- CSS3
- Movie API (TMDB)
- Fetch API
